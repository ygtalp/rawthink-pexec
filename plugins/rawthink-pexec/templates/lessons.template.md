## {group by mechanism, not by phase}

Group entries by the mechanism that produces the trap — transactions, schema,
imports, test setup — not by the phase where the trap was found.

A mechanism-grouped list can be pruned by asking "does this mechanism still
exist?". A phase-grouped list can only be pruned by age, and age is not a
measure of relevance.

Shape of an entry, using placeholder codes so nothing here can be mistaken for
a real one — real entries start at L1:

present. Never leave an example numbered entry in this file: it collides with
